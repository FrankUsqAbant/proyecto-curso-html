## 🏛️ Rutas de Entrenamiento

| Guardián | Especialidad | Retos | Enfoque |
|:---:|:---:|:---:|---|
| 🦉 **Archie** | **HTML5 Semántico** | 7 Retos | Layout semántico, accesibilidad (`a11y`), `<dialog>` y formularios. |
| 🦎 **Chroma** | **CSS3 Moderno** | 8 Retos | Flexbox, CSS Grid en 1 línea (`auto-fit`), Glassmorphism y animaciones. |
| 🦊 **Kitsune** | **JavaScript ES2024** | 8 Retos | Reactividad del DOM, delegación de eventos, `async/await` y Web Audio API. |

## ⚡ Características Principales

- 🧪 **Test Runner en Vivo:** Validador que comprueba tu código en tiempo real con pistas y soluciones.
- 💻 **Live Code Sandbox:** Editor multitab (HTML, CSS, JS) con consola de salida y previsualización aislada.
- 🏆 **Medidor de Maestría:** Seguimiento de retos superados persistido en el navegador (`localStorage`).
- 🚀 **Ultraligero:** Solo **25 KB gzip** de transferencia y carga instantánea (< 200 ms).
