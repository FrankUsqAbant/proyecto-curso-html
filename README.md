## 🦉 Los Tres Guardianes del Reino Web

| Guardián | Dominio | Enfoque Pedagógico |
|:---:|:---:|---|
| 🦉 **Archie el Búho** | **HTML5 Semántico** | Esqueleto y accesibilidad: `<main>`, `<dialog>`, `<picture>`, validación nativa de formularios y SEO sin librerías externas. |
| 🦎 **Chroma el Camaleón** | **CSS3 Moderno** | Piel y adaptabilidad: CSS Grid responsivo en 1 línea (`auto-fit`), Flexbox, variables CSS dinámicas y Glassmorphism. |
| 🦊 **Kitsune el Zorro** | **JavaScript ES2024** | Reflejos y dinamismo: Manipulación reactiva del DOM, filtrado funcional en vivo, promesas, async/await y síntesis con Web Audio API. |

## ⚡ Características Principales

- 💻 **Live Code Sandbox:** Editor interactivo multitab (HTML, CSS, JS) con previsualización en tiempo real y consola de salida integrada.
- 🎯 **Retos Guiados:** Ejercicios prácticos con objetivos paso a paso, principios teóricos y botón para cargar la solución.
- 📜 **Cheat Sheets de 1 Clic:** Colección de snippets esenciales para producción (centrado absoluto, modales nativos, debounce).
- 🚀 **Ultraligero y Rápido:** Solo **12.7 KB gzip** de transferencia de red, sin dependencias de runtime y 100% optimizado para GitHub Pages.
